whatIs: >-
  SMART目標は、1981年にGeorge T. Doranが考案した目標設定フレームワークです。Georgeは「マネジメントの目標と目的を書くSMARTな方法」と題した論文を発表し、目標達成の成功確率を高めるためのフレームワークとしてSMART目標を紹介しました。


  SMART目標は以下の要素を満たす必要があります：


  1. Specific（具体的）

  2. Measurable（測定可能）

  3. Attainable（達成可能）

  4. Realistic（現実的）

  5. Time-related（期限付き）


  SMART目標はフレームワークというよりガイドラインに近いものです。「どのように」ではなく「何を」に焦点を当てています。
whyDo: >-
  SMART目標を設定することで、目標が前進し進捗するための主要基準を満たすことが確実になります。


  1. Specific（具体的）——全員が目標が何であるかを理解することを確実にする

  2. Measurable（測定可能）——全員がこの目標への進捗がどのように測定されるかを理解する

  3. Attainable（達成可能）——この目標は自分と自分の具体的な状況に関連している

  4. Realistic（現実的）——この目標は手の届かないものではなく、達成できる

  5. Time-related（期限付き）——専用の時間枠があるため、この目標は無期限にならない
howTo: >-
  SMART目標を設定するには、作成するすべての目標がSMART目標の5つの基準を満たすことを確認する必要があります。SMART目標の構築例：


  **V1 目標**：タイピングを上達させる


  **具体的にする**：タイピング速度を上げる


  **測定可能にする**：タイピング速度を100wpmに上げる


  **達成可能にする**：自分のタイピング速度を100wpmに上げる


  **現実的にする**：タイピング速度を50から75wpmに上げる


  **期限を付ける**：3ヶ月でタイピング速度を50から75wpmに上げる
