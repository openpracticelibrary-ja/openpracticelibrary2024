whatIs: >-
  クネビン・フレームワークは、状況を5つのドメインに分類するセンスメイキングモデルです：


  * **明確（Clear）**：因果関係が存在する。ベストプラクティスと標準的な運用手順が効果的。

  * **複雑（Complicated）**：因果関係は分析によって判断できる。複数の正しい答えが存在する。専門的な分析とグッドプラクティスが必要。

  * **複合（Complex）**：因果関係は後からのみ明らかになる。実験と適応が必要。

  * **混沌（Chaotic）**：明確な因果関係が存在しない。状況を安定させるための即時行動が必要。


  **混乱/アポレティック（Confused/Aporetic）**：状況が不明確で、ドメインを判断するためにさらなる情報が必要、またはイノベーションを促すための意図的な混乱。
whyDo: >-
  

  * **意思決定の改善：** リーダーが状況の複雑さに基づいて最適な対応を選択するのに役立つ。

  * **適応力の向上：** 組織が変化する状況や複雑な課題に効果的に対応できるようにする。

  * **リスク管理の改善：** 潜在的なリスクを特定し、軽減戦略を立てるのに役立つ。

  * **コラボレーションの改善：** チームメンバー間のより良いコミュニケーションと理解を促進する。
howTo: >-
  1. **感知（Sense）：** 状況を観察し、情報を収集する。

  2. **分類（Categorize）**：状況がどのドメインに属するかを判断する（明確・複雑・複合・混沌・混乱）。

  3. **対応（Respond）**：ドメインに基づいて適切な対応を選択する：

  4. * **明確**：*感知→分類→対応。* ベストプラクティスに従う。
     * **複雑（Complicated）**：*感知→分析→対応。* 状況を分析し、専門知識を適用する。
     * **複合（Complex）**：*プローブ→感知→対応。* 実験し適応する。
     * **混沌**：*行動→感知→対応。* 状況を安定させるために行動し、より複雑または難解なドメインへ移行する。
     * **混乱/アポレティック**：より詳しく理解するためにプローブし、その後分類する。
  5. **学習（Learn）**：成果を振り返り、必要に応じてアプローチを調整する。
