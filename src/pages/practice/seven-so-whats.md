whatIs: >-
  **7つの「だから何？」** は、アイデアの潜在的な結果と影響を探るために設計された強力な批判的思考フレームワークです。継続的に「だから何？」と問うことで、解決策の表面的な理解を超え、正の波及効果か負の波及効果かにかかわらず、潜在的な連鎖反応を明らかにします。\

  \

  一般的な **「だから何？」** という問いかけの起源は、テリー・ボートンが1970年代に提唱した「What, So What, Now What（何が・だから何が・これからどうする）」フレームワークなど、教育・戦略的振り返りモデルに遡ることが多い。
whyDo: >-
  これはチームに以下を促します：


  * **実行可能な洞察を生み出す：** 静的な情報を明確な行動の呼びかけに変換し、全ての発見に目的を持たせる。

  * **結果を探る：** アイデアの下流への影響について体系的に考えることを強制し、意図しないアウトカムに不意をつかれないようにする。

  * **オーナーシップの文化を構築する：** チームメンバーが洞察を結果に変える責任を取ることを促し、プロアクティブで説明責任のある環境を育む。

  * **意思決定を改善する：** 発見をその意味に結びつけることで、チームはより情報に基づいた戦略的な決定を下せる。
howTo: >-
  

  1. **アイデアまたは推奨事項を述べる。**

  2. **最初の「だから何？」を問う：** このアクションの直接的な結果は何ですか？答えを書き留める。

  3. **さらに6回プロセスを繰り返す：** 前の結果を取り、再び「だから何？」と問う。これにより、決定の影響の層を剥がして、各答えの下流への影響について考えることを強制します。


  このプロセスの最後には、最初のアイデアの結果についてはるかに包括的な理解が得られ、より堅牢で十分に検討された決定につながります。
